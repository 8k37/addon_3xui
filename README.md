# 3x-ui для Home Assistant

Home Assistant add-on: [3x-ui](https://github.com/MHSanaei/3x-ui) — панель управления Xray (Vmess, Vless, Trojan, Shadowsocks, WireGuard).

## Кнопка добавления в Home Assistant

[![Добавить репозиторий в Home Assistant](https://my.home-assistant.io/badges/repository_add.svg)](https://my.home-assistant.io/redirect/repository_add/?repository_url=https%3A%2F%2Fgithub.com%2F8k37%2Faddon_3xui)

Нажмите кнопку — откроется Home Assistant и предложит добавить репозиторий в магазин аддонов. После этого установите аддон **3x-ui**.

## Ручное добавление

1. **Настройки → Аддоны → Магазин аддонов → Три точки → Репозитории**
2. Вставьте: `https://github.com/8k37/addon_3xui`
3. Установите аддон **3x-ui** и запустите его.

Документация — в [3x-ui/DOCS.md](3x-ui/DOCS.md).
