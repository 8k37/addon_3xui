# addon_3xui

Home Assistant add-on: [3x-ui](https://github.com/MHSanaei/3x-ui) — панель управления Xray (Vmess, Vless, Trojan, Shadowsocks, WireGuard).

## Добавление репозитория в Home Assistant

1. **Настройки → Аддоны → Магазин аддонов → Три точки → Репозитории**
2. Вставьте: `https://github.com/8k37/addon_3xui`
3. Установите аддон **3x-ui** и запустите его.

Документация — в [3x-ui/DOCS.md](3x-ui/DOCS.md).
