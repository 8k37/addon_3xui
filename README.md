# addon_3xui

Home Assistant add-on: [3X-UI](https://github.com/MHSanaei/3x-ui) — веб-панель
для управления Xray (Vmess, Vless, Trojan, Shadowsocks, WireGuard).

## Установка

1. В Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**,
   добавьте `https://github.com/8k37/addon_3xui`.
2. Установите аддон **3X-UI**, запустите.
3. Панель: `http://<адрес-HA>:2053/` (логин/пароль по умолчанию `admin`/`admin`
   — смените сразу).

Подробнее — в [DOCS.md](3x-ui/DOCS.md).
