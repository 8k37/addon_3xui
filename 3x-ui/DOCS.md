# 3X-UI — панель Xray для Home Assistant

Аддон запускает [3X-UI](https://github.com/MHSanaei/3x-ui) — веб-панель для управления
Xray (Vmess, Vless, Trojan, Shadowsocks, WireGuard и др.).

## Первый запуск

1. Установите аддон и запустите его.
2. Панель доступна по адресу `http://<адрес-HA>:2053/`
   (порт настраивается опцией `panel_port`, применяется при старте).
3. Логин/пароль по умолчанию: `admin` / `admin` — **сразу смените их** в
   Panel Settings.

## Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `panel_port` | `2053` | Порт веб-панели. Применяется при старте аддона |

## Данные

База данных панели (`x-ui.db`) хранится в `/data` аддона — переживает
обновление и пересоздание контейнера. Для бэкапа используйте снимки
Home Assistant (папка аддона включается в бэкап автоматически).

## Сеть

Аддон работает в режиме `host_network`: все входящие подключения Xray
(инбаунды) работают сразу, без маппинга портов. Порт панели также
открыт на хосте.

## Важно

- Панель поднимается на `0.0.0.0` — не выставляйте порт панели наружу
  без смены стандартного логина/пароля и (желательно) включения HTTPS
  в настройках самой панели.
- Секретный URI для входа (`web base path`) можно задать в настройках
  панели — тогда панель будет доступна по `http://<host>:<port>/<path>`.
